# VisionTrack Connect

Build a complete, production-quality web platform called VisionTrack.

VisionTrack is an AI-powered missing-person search and identification platform designed to help authorized organizations, families, and search teams organize missing-person cases, analyze submitted visual evidence, and accelerate the process of identifying possible matches.

The website must feel like a real startup product that was designed and engineered by a professional product team. Do NOT make it look AI-generated, template-based, generic, or like a Lovable demo. Avoid excessive gradients, excessive rounded cards, unnecessary animations, fake statistics, generic stock illustrations, and repetitive AI-dashboard patterns.

The product should feel trustworthy, serious, modern, human, and mission-driven.
